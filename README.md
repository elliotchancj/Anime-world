# Nohara House 3D

An unofficial, non-commercial fan recreation of the Nohara family house and street from Crayon Shin-chan, playable in the browser.

**Crayon Shin-chan © Yoshito Usui / Futabasha / Shin-Ei / TV Asahi / ADK.**  
All models are built in code; no official assets are included.

## Play Now

[**Play the game**](https://elliotchancj.github.io/Anime-world/)

## Controls

### Desktop
- **WASD** or **Arrow keys** — Move
- **Shift** — Run
- **Space** — Jump
- **B** — Dance
- **E** — Open/close doors
- **F** — Fullscreen
- **Mouse drag** — Orbit camera
- **Mouse scroll** — Zoom in/out
- **Click objects** — Inspect

### Mobile
- **On-screen joystick** — Move
- **Tap objects** — Inspect
- **Pinch** — Zoom
- **Drag** — Orbit camera
